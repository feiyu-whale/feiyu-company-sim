# 公司经营模拟 · Business Tycoon Sim

一个**硬核**的餐饮创业模拟游戏。参数全部取自真实上市公司年报与公开行业数据。

> ⚠️ **免责声明**
> 本游戏按真实餐饮行业数据建模。餐饮业门店年倒闭率超 60%，平均寿命 508 天。
> **默认结果是失败。** 请勿以此作为创业决策依据。

## 玩法

开局四步：

1. **选品类** — 正餐 / 火锅 / 快餐 / 茶饮（参数来自真实财报）
2. **选城市与商圈** — 29 个真实城市 × 3 档商圈
3. **选开局年份** — 2019~2026，每年历史环境不同
4. **选创业或加盟** — 自建品牌，或加盟（有概率踩到野鸡品牌）

## 系统

| 系统 | 说明 |
|---|---|
| 现金流 | 堂食现结，外卖 T+15，团购 T+30 |
| 新店爬坡 | 第一家店也要 10 个月才爬满客流 |
| 三级组织 | 总部 / 公司化，可以不建，但风险累积 |
| 风险爆发 | 该建没建，累积到阈值集中爆发 |
| 竞争对手 | 按城市算对手数，会成长、打价格战、挖人 |
| 借贷 | 信用评分、授信额度、等额本息、逾期罚息 |
| 抵押 | 设备 50% / 装修 30% / 房产 70% 折价 |
| 供应商账期 | 现结有折扣，长账期报价高、断供风险大 |
| 对赌协议 | 三档，输了赔钱或丢控制权 |
| IPO 上市 | 真实门槛，万分之一量级 |
| 违法操作 | 劣质油 / 偷税 / 黑工 / 刷单 |
| 被查之后 | 自首 / 打点 / 销毁证据 / 硬扛 |
| 官员关系 | 打点后一直要钱，还可能落马供出你 |
| 历史时间线 | 2020 疫情 → 2023 反弹 → 2024 消费降级 |

## 数据来源

- 成本结构：A 股 + 港股 15 家餐饮上市公司年报（东方财富 datacenter 接口）
- 城市数据：公开统计年鉴（人口、人均可支配收入）
- 餐饮规模、商铺租金：按公开行业规律推算，非逐城实测

**所有品牌名均为虚构**，商业逻辑取自真实现象。

## 运行

纯静态页面，无需后端：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

